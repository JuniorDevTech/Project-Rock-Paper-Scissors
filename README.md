# Pierre - Feuille - Ciseaux

Mini projet réalisé dans le cadre de The Odin Project.

## Fonctionnalités

- Jouer contre l'ordinateur
- 5 manches par partie
- Calcul automatique du score
- Affichage du gagnant final
- Bouton pour recommencer une partie
- Interface moderne et responsive

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Aperçu

Le joueur choisit :

- Pierre 🪨
- Feuille 📄
- Ciseaux ✂️

L'ordinateur choisit aléatoirement une option et le score est mis à jour après chaque manche.
